The two files are from part of our research on classifying retinal images (OCT and SLO) of individuals with MS and healthy controls:

AlexNet_PyTorch: an example of our code based on the AlexNet, implemented in PyTorch.

ResNet50_TF: an example based on the ResNet50 architecture, implemented in TensorFlow


Note: I am currently adding more comments and making some modifications to improve the code’s readability and make each step easier to follow.
